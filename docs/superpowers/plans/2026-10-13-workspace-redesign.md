# Workspace redesign implementation plan

Goal: Replace the login, assignment queue, ticket workspace, topology and chat presentation while preserving API behavior.
Architecture: Existing React routes and data contracts; shared warm paper/graphite/orange visual tokens. Generated telecom illustration establishes product identity. Accessible Radix dialog manages the assistant. Motion explains entrances, selection and feedback with reduced-motion support.

- [ ] Rebuild login composition and password visibility control.
- [ ] Rework workspace navigation, incident rows, search and queue hierarchy.
- [ ] Restructure ticket overview and topology device presentation; preserve keyboard device selection.
- [ ] Replace assistant modal behavior and unify staff/customer chat visuals.
- [ ] Integrate generated illustrations, verify production build and existing behavior tests, inspect desktop/mobile rendering.

Design purpose: Orange identifies primary actions; graphite anchors navigation; warm surfaces separate reading areas. Device cards communicate equipment and state. Illustration is confined to welcome/empty contexts. Entrances use 240ms opacity/transform; frequent controls use 140ms feedback; no decorative loops.
